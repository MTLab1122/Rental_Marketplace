# Peshawar Rental Marketplace — Comprehensive Threat Model

Phase 16: Application Security Hardening & Threat Analysis (STRIDE / OWASP ASVS Level 2)

This document establishes the official application security threat model for the Peshawar Rental Marketplace, covering the NestJS backend API, Flutter mobile app, Next.js tenant web application, and Next.js administrative control console.

---
