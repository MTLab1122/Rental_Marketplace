# Tenant Acquisition Playbook - Peshawar

## 1. Funnel Architecture & Key Milestones

```
[ Top-of-Funnel Visitor ]
    │ (Organic SEO, Programmatic Locality Hubs, Campus Ads)
    ▼
[ Category Selector ]
    │ (Student vs Family toggle - sets strict feed eligibility)
    ▼
[ Search & Discovery ]
    │ (Faceted search by locality, rent range, BRT proximity)
    ▼
[ Listing Deep Dive ]
    │ (Property details, verified photo gallery, utility norms)
    ▼
[ Intent Signals ]
    │ (Saved to favorites, saved-search alert created)
    ▼
[ Formal Inquiry ]
    │ (Direct structured inquiry sent to verified landlord)
    ▼
[ Landlord Engagement ]
    │ (Real-time in-app chat, WhatsApp number reveal)
    ▼
[ Transaction Closure ]
    │ (Digital agreement generation, security deposit escrow)
```

## 2. High-Converting Landing Page Ecosystem

1. **Student Landing Page (`/students`)**:
   - Focuses on proximity to UOP, Islamia College, KMC faculties.
   - Highlights mess details, Wi-Fi speeds, curfew times, and per-bed pricing.
2. **Family Landing Page (`/families`)**:
   - Emphasizes secure portions, independent meters, nearby parks, and school access.
3. **Programmatic Locality Hubs (`/rentals/peshawar/[localitySlug]`)**:
   - Immediate neighborhood rent tables and transit connectivity benchmarks.

## 3. High-Intent Conversion Mechanisms

- **Zero Commission Guarantee**: Prominently display _"No Agent Commission — Rent Directly from Verified Landlords"_.
- **Instant Search Alerts**: Prompt visitors searching for specific filters to save their search and receive instant push/WhatsApp alerts for new matching listings.
- **WhatsApp Social Sharing**: One-click sharing formatted for family and student group chats: _"Found this 2-bed flat in Phase 5 Hayatabad for PKR 38,000. Check it out on RentPeshawar: [link]"_.

## 4. University Intake Campaign Calendar

- **Fall Semester Rush (July 15 - September 15)**: Peak hostel demand; aggressive campus brand ambassador presence and flyer distribution at university admission offices.
- **Spring Intake (January 10 - February 28)**: Medical student rotation transfers and post-graduate enrollments; focus on private apartments in University Town and Hayatabad.
